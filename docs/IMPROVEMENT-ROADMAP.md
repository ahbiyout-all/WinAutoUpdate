# 개선 로드맵 (v0.1.44 이후)

사용자 요청에 따라 아래 순서대로 개선을 진행합니다.
각 개선이 끝나면 **자아성찰 10회**를 수행하고 다음 개선으로 넘어갑니다.
게시(커밋·태그·Release)는 모든 개선 완료 후 별도 승인을 받아 진행합니다.
사용자 명시 승인을 받아 `v0.1.45`를 게시했고, 관리자 토큰 안내 정정을 위해 `v0.1.46`을 추가 게시했습니다.

## 공통 제약

- 기존 게시 버전(`v0.1.44` 이하)의 커밋·태그·Release는 변경하지 않습니다.
- 문서는 한국어, 배치/스크립트 도움말·메시지는 영어를 유지합니다.
- 토큰 원문은 로그·리포트·명령줄·저장소에 남기지 않고, 파일의 첫 줄만 읽습니다.
- placeholder 토큰은 fail-closed, 시스템 브라우저 `--app=` 사용, WebView2 금지.
- 기능 업데이트는 계속 비활성, Server Core 오버레이는 계속 비활성.
- 새 DLL은 외부 NuGet 의존성 없이 자작 C#만 사용합니다.
- 방화벽은 교사 PC TCP 5080 Domain/Private 인바운드만 사용하고, 학생 PC 인바운드 규칙은 만들지 않습니다.
